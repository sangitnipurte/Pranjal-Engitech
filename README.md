# Pranjal Engitech
Professional industrial website based on the supplied Pranjal Polymers catalogue structure. Product names/catalogue are preserved.

## Important
The public frontend is in `frontend/` and is intended for Vercel. The Flask backend is intended for Render. MongoDB Atlas stores content and Cloudinary stores images.

The public navigation does not contain an Admin link. The admin CMS is directly accessible at `/admin`.

See `VERCEL_RENDER_SETUP.md` for deployment.
